A product built from the shell: ANDOR Example

ANDOR Example was written by tools/create_andor_instrument.py and builds as its own plugin (plugin code Aexm). It plays through the shell's labelled diagnostic engine: a plain resampler, or a test tone with no sound loaded. That engine reads only LEVEL, PAN, TUNE, MUTE/SOLO, the AMP envelope, volume, fine tune, bend and velocity range, so every other control is shown disabled in ANDOR OSP's own disabled look, and the footer says what it is.
