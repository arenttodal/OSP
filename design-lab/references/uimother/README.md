# UI Mother — Eclyde (reference only)

No purchased Eclyde source files are available in this repository or environment. The only
references are four preview images shared in the conversation (dark UI, brushed gold /
aluminium knobs, amber glowing pads, recessed sliders with an orange fill).

Licensed kit assets must not be added to this repository (it may be public). If the kit is
used in a later round, keep its files outside the repository and record here only what was
learned from it.
