# P0 — Reference corpus and ground truth

**Status:** P0 gate passed. All 24 fixtures load reproducibly, with exact ground truth for
transcription (note events) and extraction (each note's isolated stem).

## What was implemented

- **`polyphonic_lab/fixtures/synth.py`:** a deterministic instrument synthesiser (numpy PCG64 seeds).
  - **Piano** (physically informed):
    - inharmonic partials, `f_k = k f0 sqrt(1 + B k²)`, with B rising with register;
    - 1–3 unison strings per key, a fraction of a cent apart (beating);
    - a hammer-position comb at about 1/8 of the string;
    - a spectral slope that depends on velocity;
    - a two-stage decay per partial;
    - band-passed hammer noise of a few ms;
    - the damper on key release;
    - with the pedal: no dampers, plus sympathetic resonance about 30 dB down. This resonance is
      stored as *residual* ground truth, never as a note.
  - **Organ:** stationary drawbar harmonics.
  - **Guitar:** Karplus-Strong.
  - **Strings:** harmonic tone with vibrato.
  - **Voices:** formant vowel "ah" with vibrato and breath.
- **`fixtures/corpus_def.py`:** the fixture definitions (below).
- **`corpus.py`:**
  - `generate` writes every mix, each note's isolated stem and a JSON manifest (schema
    `osp-poly.fixture/1`) with the fixture ID, input path and SHA-256, sample rate, channels,
    frames, family, complexity, ground-truth notes, stems, expected failures and provenance/licence.
  - `validate` checks hashes, formats and that the stems sum to the mix (within 1e-5). It writes
    `summary.md`, `summary.json`, a spectrogram with the known-note timeline per fixture, and
    `evaluation-manifest.json` (the transcription and extraction tasks).
- **CLI:** `osp-poly corpus generate|validate`. A nonzero exit code means invalid or missing.

## Fixtures

| Class | Fixtures | Notes |
|---|---|---|
| A single notes | C4, E4, G4, C5, C2 (velocity 0.8, held 2 s); C4 soft (0.4); C4 short (0.5 s) | the quality a clean extraction should approach |
| B chords | C major, A minor, Cmaj7, Dm7, close C-D-E, wide C2-G3-E4-C6 | struck together, held 2 s |
| C overlap | C4+G4 together; C4 then E4 +150 ms; C3 held with E4 entering at 1 s; G4 repeated three times; four-note melody over a C3 triad | |
| D phrase | C - Am - F - G with a melody, ±15 ms timing, varied velocity | **synthetic stand-in**: a recorded performance (Fixture D proper) is pending |
| E pedal | C3 E3 G3 C4 arpeggiated with the pedal down | long tails; sympathetic residual |
| F other | organ C major; guitar E major strum; strings A minor (vibrato); three-part vocal harmony | secondary benchmarks |
| G mixed | not generated (P5) | |

The validation output (`output/corpus-report/summary.md`, regenerated by `corpus validate`) lists
every fixture's maximum polyphony (1–8), duration, peak and RMS.

## Found on the way

libsndfile writes a **PEAK chunk with a timestamp** into float WAVs, so the same audio written a
second later hashed differently. That breaks determinism, and OSP identifies an atlas's sources by
their files' bytes. `audio.write_audio` now turns the PEAK chunk off, and a test checks that hashes
are stable.

## Tests

`pytest`: 7 passed.
- Unique IDs and every class present.
- Generation deterministic (identical hashes across runs) and the result validates.
- Committed manifests match the generator.
- Stems sum to the mix and are finite.
- A piano note is silent before its onset, pitched (C4 within 3 Hz) and damped after release.
- The STFT round trip is exact (< 1e-9).

## Limitations

- **Synthetic ground truth only.** The synthetic piano follows its model exactly: partials sit
  where the model says, with no room, microphones or soundboard. Separation on it may be easier or
  harder than on a real piano. Every extraction result must be confirmed on real recordings
  (Fixture D, and the user's material) before any conclusion about the product.
- Mono, 48 kHz only. Stereo handling is in the pipeline, but no fixture tests it yet.

## Reproduce

```bash
cd research/polyphonic-lab
.venv/bin/osp-poly corpus generate && .venv/bin/osp-poly corpus validate && .venv/bin/pytest -q
```
