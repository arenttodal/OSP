Discovery, architecture and wireframes for review

Gate 0 read the current code on the release line (6ef3376, 0.9.0-beta.1 plus Custom Pattern UX R2) and ran its Learn, capture and real-window tests. No product, test or website code was written. Five decisions are needed before Gate 1.

Reuse, don't rebuildLearn 2.0 targets and states, real-window mouse events, menu compositing, the tutorial sounds and the live-input test path cover most of the capture runner.
Shipping plugin unchangedThe runner is a separate test-only build target. Nothing is added to the plugin for Gates 1–2.
Seven features have no Learn coverageLive capture, GRAB LAST, per-source ARP, Custom Patterns, STRUM, SATELLITE and SYNTH/IMPRINT have no lesson, target or Info topic.
One honest gapRouting a DAW track into OSP's Sidechain input has never been tested on a Mac. That guide step stays flagged until it is.

Grab what you just played

OSP keeps the last minute of its audio input. GRAB LAST turns what you just played into this layer's notes, without pressing record first.

SATELLITE

Function

Moves each layer in the stereo field on its own path, at a tempo-synced or free rate. It works with or without the arpeggiator.

Location

The ARP panel's title row. The light switches the moving layers on or off; the name opens the panel. The chips A B C show a layer's settings.

Parameters
ControlValuesDoes
ModePAN · ORBIT · BOUNCESide to side; round, quieter and darker behind; from side to side
TimingSYNC · FREERATE as a note value (4 BARS … 1/32) or in Hz
DEPTH · WIDTH%How far it moves; how wide the path is
PHASE · OFFSETdegrees · positionWhere each layer starts on its path
Guides

Move each layer in the stereo field · Give each layer its own arpeggio

Every value in a reference table is read from the parameter schema at the pinned commit, and the build lists any article whose parameters changed since it was checked.
