# ANDOR OSP — product renders

Photoreal renders of ANDOR OSP as a physical object, built in Blender (Cycles) from the genuine
editor capture. Stage: **first deliverable for approval** (one 9:16 hero and its transparent
render). The rest of the suite (gallery, close-up, 4:5, 16:9, square, motion) waits for approval.

```
blender/scripts/   prep_textures.py (capture → textures + measured geometry)
                   andor_scene.py   (scene, materials, lights, cameras, render; headless bpy 4.2)
                   compose_ad.mjs   (advertising type over a render, with optional safe-zone guides)
blender/textures/  generated by prep_textures.py (git-ignored: derived from the capture)
renders/           instagram_9x16/, transparent/, review/  (committed: optimised outputs)
documentation/     source_manifest, camera_settings, materials, render_settings
```

## Regenerate
```sh
# 1. capture (OSP repo root; see andor-web/tools/capture.sh)  → assets/source/captures/
# 2. textures + geometry
python3 product-renders/blender/scripts/prep_textures.py
# 3. render (Python 3.11 + pip install bpy==4.2.0)
python product-renders/blender/scripts/andor_scene.py -- --variant combined --res 1080 1920 --samples 256 \
    --out product-renders/renders/instagram_9x16/osp_hero_9x16.png --save-blend andor_master.blend
python product-renders/blender/scripts/andor_scene.py -- --variant alpha --res 1080 1920 --samples 192 \
    --out product-renders/renders/transparent/osp_hero_9x16_alpha.png
# 4. type (optional)
node product-renders/blender/scripts/compose_ad.mjs <render.png> <out.png> [--guides]
```
