# ANDOR — Launch Creative Playbook
Version 1.0 · 18 November 2026 · Owner-approved creative direction; living production document.

Companion: [Blender motion library](blender-motion-library.md). Verify feature claims against the shipping build.

## 1. North star
Launch ANDOR like a boutique musical instrument, not a generic software utility. Combine high-end industrial design photography, human musicianship, authentic plugin interaction and emotionally compelling sound. A few exceptional films and iconic stills matter more than dozens of mediocre ads. Establish a repeatable production system rather than reinventing each campaign.

**One sound. An entire instrument.** OSP turns a recording into a playable musical world. Preserve breath, bow, noise and imperfections. The imagery sells the craftsmanship; the sound sells the instrument.

Creative touchstones: Apple product-launch precision, Teenage Engineering curiosity, Scandinavian editorial restraint, and the musical sensibility of Bon Iver, Radiohead and Sigur Rós. Website quality benchmark: thelibrary.fm. Photography benchmark: the supplied Granello advertisement, without copying its identity.

## 2. Four creative worlds
- **The Object:** actual Blender master, ivory ceramic, teak, fluted knobs, glass, light and physical craftsmanship.
- **The Human:** hands, real instruments, recording, musical expression and imperfection; intimate and unforced.
- **The Process:** authentic OSP screen captures, waveforms, loading, playing, modulation and sound manipulation.
- **The Emotion:** the world the music evokes; atmosphere, texture, imagination. Scandinavian landscapes or abstract imagery only when they serve the music.

Use these as interconnected ingredients, not four obligatory sections in every short film. No generic stock footage in final campaigns, fake UI or fictional functionality.

## 3. Three flagship films
### Film 01 — One Sound (45–60 seconds)
Flagship brand film: one real nyckelharpa recording becomes an entire musical world. Compose the piece before locking the edit. Ideally all musical layers genuinely derive from that recording; if additional sources are used, disclose them and adjust the claims. No generic advertising soundtrack or trailer drums. Intimate, fragile, experimental and beautiful; gradually introduce harmony, granular texture, rhythmic movement and space.

| Time | Image and sound |
|---|---|
| 00:00–00:04 | Bow meets string; one completely unprocessed note, audible friction and breath. No logo or music underneath. |
| 00:04–00:08 | Actual recording appears in OSP; first playable notes emerge. |
| 00:08–00:15 | Macro and display photography intercut with genuine control interaction; sound gains life, width and expression. |
| 00:15–00:25 | Real MIDI keyboard performance, chords, melodies and movement. |
| 00:25–00:38 | Emotional peak; performance, waveform motion, material details, optional original atmospheric footage. |
| 00:38–00:48 | Slow full-product reveal and musical resolution. ANDOR / OSP. |
| Final beat | “One sound. An entire instrument.” One Shot Performer; appropriate launch CTA. |

Timing is an editable starting point. Produce the flagship master, a 15-second cut and a 6-second reveal. Product motion supports the composition, not the reverse.

### Film 02 — Made From This (15–30 seconds)
Repeatable performance format: **I made this music from this sound.** Record (0–3s), transform in real OSP (3–7s), perform (7–25s), optional short end card. Start with the recognizable dry note, then hear the payoff quickly. Test a performance-first alternate hook.

Series identity: AN ANDOR SOUND SERIES / Made from this. / 001 — Nyckelharpa.

| Original sound | Reimagined instrument |
|---|---|
| Single nyckelharpa note | Expansive cinematic strings |
| Breathy vocal note | Ethereal choir |
| Hardanger fiddle note | Animated orchestral texture |
| Acoustic guitar harmonic | Dreamlike ambient keys |
| Prophet-6 note | Evolving organic synthesizer |
| Bouzouki pluck | Rhythmic textured arpeggios |
| Old piano note | Fragile Mellotron-like instrument |
| Bowed cymbal | Otherworldly tonal soundscape |

Each session can yield a Reel, ad, website audio demo, full performance, preset and original recording (when rights permit). Prioritize unusual real sounds and original music. Show honest source-to-output causality.

### Film 03 — From Sound to Instrument (60–90 seconds)
Flagship workflow demonstration, not a feature checklist. Quiet pacing, legible real UI, audible transformation.

| Time | Demonstration |
|---|---|
| 0–5s | Original dry recording |
| 5–12s | Drop sound into OSP and immediately play |
| 12–22s | Expression and character via macros |
| 22–32s | REIMAGINED and granular transformation |
| 32–42s | Additional layer or SYNTH + IMPRINT (if shipping) |
| 42–52s | Movement and modulation |
| 52–65s | Perform finished instrument |
| 65–70s | Product reveal and brand message |

Export individual chapter clips for the website. No frantic zooming or generic corporate voiceover. Make every demonstrated feature audible.

## 4. Motion and still campaign
Use the companion brief for eight reusable 5–10 second Blender shots: Gallery reveal, Dark orbit, Macro glide, Inside the sound, Keybed, Material, Expression, Interface. Render without text or music. Integrate with real performances during editing, rather than creating three all-CGI ads. Later explore driving Blender display and control animations from real captured parameter automation and waveform activity.

Three initial still concepts (approved C3 imagery or original photography, live typography):
1. **The product** — dark architectural B1/B2; “One sound. An entire instrument.”
2. **The philosophy** — warm ivory macro photography; “Hear the extraordinary in the ordinary.”
3. **The possibility** — real source instrument; “Your next instrument is one sound away.”

All use the appropriate approved CTA (e.g. Discover OSP). One visual identity, different motivations.

## 5. Repeatable content-production system
One source sound + one preset + one performance = one reusable content session. Capture camera footage, actual plugin footage and clean audio independently. Edit using shared Blender clips, typography, grade, mix and end cards. Output organic Reel, paid cut, website sound demo, preset demo, still and YouTube Short as appropriate.

### Session checklist
- [ ] Record original dry source in high quality.
- [ ] Film the acoustic instrument and recording process.
- [ ] Screen-record actual OSP sound design.
- [ ] Record clean plugin output separately from camera audio.
- [ ] Film finished MIDI keyboard performance.
- [ ] Save source, preset, MIDI, automation and DAW project.
- [ ] Export level-matched dry and processed examples.
- [ ] Capture clean preset screenshot; record build/commit and parameter settings.
- [ ] Sync camera/audio/screen via slate or timecode; retain original takes and usage rights.

### Reusable episode record
Episode ID / source / recording date / artist / source audio / preset / DAW session / MIDI / automation / plugin version / real UI clips / camera takes / clean audio / hook options / edit version / CTA / ratios / website placement / rights / approval.

Suggested folder: `episodes/001-nyckelharpa/{source,session,performance,screen,audio,edits,exports,notes}`. Adapt to existing storage. Store bulky media outside Git; keep metadata and reproducible scripts in Git.

### Paid creative tests
Reuse strong performances and vary opening hooks rather than creating unrelated ads. Examples (only if factually true):
- Everything you hear came from one note.
- What if a nyckelharpa was a synthesizer?
- This isn't a string library.
- I recorded this sound. Then I made this.
- Stop searching for presets. Make your own instruments.

Compare hook, duration, first frame, CTA and format independently. Track retention, click-through and conversions when launched. No invented testimonials, unsupported claims or uncleared material.

## 7. Initial launch kit and sequence
Target: 3 flagship films, 8 reusable Blender shots, 6 short video ad variations, 3 still concepts, 5 signature sound demonstrations, 1 repeatable content system. Select quality over count.

Illustrative four-week sequence (not a launch commitment):
1. Creative development: composition, references, shot lists, motion tests.
2. Recording and filming: acoustic source, actual OSP use, genuine performance.
3. Editing and finishing: flagship films, sound mix, colour grade.
4. Campaign production: hooks/cuts, responsive exports, website and templates.
