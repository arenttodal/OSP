# Framer

The Framer build is fully specified in **`docs/FRAMER_BUILD_GUIDE.md`**, with the values to enter in
**`docs/FRAMER_CONTENT.md`** (generated) and the code components in **`framer/`** (tested by
`npm run framer:test`, kept in step by `npm run framer:check`). Framer owns layout, text, CMS and
publishing; the repo owns the code components, assets, tests and docs.
