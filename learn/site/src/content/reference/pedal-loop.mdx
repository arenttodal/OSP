## How the loop is chosen

OSP analyses a recording's loop regions in the background. A sound that sustains gets its best loop; a decaying sound (a pluck, a piano note) gets up to eight short regions along its decay. When the pedal goes down, the note loops in the first region that is still ahead of where it is playing, so a pedal pressed late in the decay holds the sound close to where it already is.

- **With LOOP on**, a sustaining sound already holds through the layer's own loop; Forward then changes nothing there. Ping-Pong always takes over while the pedal is down.
- **Pedal up, key still held:** the note continues from the loop into the rest of the recording.
- **Key up, pedal still down:** the note keeps looping until the pedal is released.
- If a recording has no usable loop, the menu shows "No suitable loop found for this recording".
